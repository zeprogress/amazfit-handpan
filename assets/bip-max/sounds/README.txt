Handpan tone samples (D Kurd)

Files needed:
  ding.mp3  (D3 ~146.8 Hz)
  a3.mp3    (A3 220 Hz)
  bb3.mp3   (Bb3 ~233 Hz)
  c4.mp3    (C4 ~262 Hz)
  d4.mp3    (D4 ~294 Hz)
  e4.mp3    (E4 ~330 Hz)
  f4.mp3    (F4 ~349 Hz)
  g4.mp3    (G4 392 Hz)
  a4.mp3    (A4 440 Hz)

Generate synthetic samples (requires Python 3 + ffmpeg):

  python3 scripts/generate_assets.py

This also creates assets/bip-max/icon.png

Recommended: mono MP3, 16-24 kHz, 0.8-2 seconds each.
