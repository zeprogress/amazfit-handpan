# Amazfit Handpan 🥁

Виртуальный хэндпан для **Amazfit Bip Max** (Zepp OS 5).

Нажимай на разные зоны экрана — и слышишь настоящие тона хэндпана.

## Возможности

- 9 зон (классическая гамма **D Kurd**)
- Визуальная подсветка при ударе
- Вибрация при касании
- Красивый круглый дизайн под хэндпан
- Поддержка экрана 432×514 (Bip Max)

## Установка

### Способ 1: Zeus Preview (рекомендуется)

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/zeprogress/amazfit-handpan.git
   cd amazfit-handpan
   ```

2. Установи Zeus CLI:
   ```bash
   npm i @zeppos/zeus-cli -g
   ```

3. Добавь звуковые файлы (см. ниже)

4. Запусти превью:
   ```bash
   zeus preview
   ```

5. В Zepp App включи **Режим разработчика**:
   - Профиль → Настройки → О программе → нажми логотип Zepp 7 раз

6. Отсканируй QR-код из терминала через «Сканировать» в режиме разработчика.

### Способ 2: Сборка .zab

```bash
zeus build
```

Получится файл `.zab`, который можно установить через инструменты разработчика.

## Звуки

Положи mp3-файлы в папку:

```
assets/bip-max/sounds/
├── ding.mp3   (D3 — центральный Ding)
├── a3.mp3
├── bb3.mp3
├── c4.mp3
├── d4.mp3
├── e4.mp3
├── f4.mp3
├── g4.mp3
└── a4.mp3
```

Рекомендации к файлам:
- Формат: **MP3**
- Длительность: 0.8–2 секунды
- Каналы: моно
- Частота: 16–24 кГц

Можно взять сэмплы с Freesound.org или записать с настоящего хэндпана.

## Гамма D Kurd (по умолчанию)

```
        A4
   A3        Bb3
C4              D4
   E4    F4   G4
        Ding (D3)
```
